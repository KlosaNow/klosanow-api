# Klosanow API

Houses all Klosanow API codes

#### To install

checkout of master into <devname-branchName> and run `yarn install`

#### To run

run `yarn run dev` or `npm run dev` to start the dev server

### To install

run `yarn add` <packagename>

### To uninstall

run `yarn remove` <packagename>
